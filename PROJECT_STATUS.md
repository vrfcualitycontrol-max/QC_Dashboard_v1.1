## ⚠️ КРИТИЧЕСКИЕ ПРОБЛЕМЫ

### 1. Бэкенд не работает
- **Симптом:** `ERROR: Error loading ASGI app. Could not import module "app"`
- **Причина:** Файлы `/app/app.py` и `/app/init_db.py` повреждены или отсутствуют в контейнере
- **Влияние:** API эндпоинты недоступны → многостраничные HTML не получают данные

### 2. nginx циклическая переадресация
- **Симптом:** `rewrite or internal redirection cycle while internally redirecting to "/index.html"` → 500
- **Причина:** Ошибка в nginx.conf (try_files зацикливается)
- **Влияние:** Страницы не загружаются через proxy

### 3. Многостраничные HTML отсутствуют в Dashboard_SC
- По ТЗ v1.2.2 нужны 21 страница (summary, heatmap, analytics, employees, settings, tools/, regulations/)
- В Dashboard_SC есть только `index.html` (одностраничный)
- В nginx контейнере файлы HTML есть (видны в curl выводах), но они НЕ работают из-за п.1 и п.2

### 4. Данные в PostgreSQL могут быть устаревшими
- Бэкенд не может подключиться → данные не обновлялись
- Последние логи API показывают успешные запросы, но это до падения

### 5. Несовместимость данных
- Dashboard_SC: `months -> periods[]`, SVP ключи кириллица, TQS 0-100
- Dashboard_QC: `periods{}`, SVP ключи латиница, TQS 0.0-1.0
- PostgreSQL: неизвестная схема (нужно изучить)
