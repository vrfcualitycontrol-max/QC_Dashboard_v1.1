# QC Dashboard v1.2.2 — Структура комнат

> Предложенная структура многокомпонентного приложения.
> Жду корректировок от пользователя.

---

## 🏠 Общая концепция

Вместо одного `index.html` — **6 отдельных комнат** с боковой навигацией.
Переход между комнатами мгновенный (SPA-роутинг через `#hash`).

```
┌──────────────────────────────────────────────┐
│  Sidebar (меню)    │                         │
│                    │    Main Content Area     │
│  🏠 Главная        │                          │
│  📊 Сводка          │    ← Здесь "комната"     │
│  🔥 SVP Heatmap    │                          │
│  📈 Аналитика      │                          │
│  👥 Сотрудники     │                          │
│  ⚙️ Настройки      │                          │
│                    │                          │
└──────────────────────────────────────────────┘
```

## 🗺️ Комнаты (подробно)

### 🏠 Комната 1: Главная (`home.html`)
**Назначение:** Приветствие, выбор периода, обзор

| Блок | Описание |
|------|----------|
| Приветствие | Логотип, название, текущая дата |
| Фильтры | Месяц, период, сотрудник (общие для всего приложения) |
| Быстрые карточки | Общий TQS команды, средний AHT, кол-во звонков |
| Последние обновления | Дата последнего парсинга, статус |

**Зависимости:** `common.js`, `sidebar.js`, `theme.js`, `rooms/home.js`

---

### 📊 Комната 2: Сводка (`summary.html`)
**Назначение:** Обзорные метрики, лидерборд, тренды команды

| Блок | Описание |
|------|----------|
| Карточки метрик | TQS команды, AHT, всего звонков, активных сотрудников |
| 🏆 Лидерборд | Топ-10 сотрудников с трендами (up/down/stable) |
| 📈 Линейный график | Динамика TQS команды по периодам |
| 🔴 Критические зоны | Сотрудники с TQS < 60%, проблемные критерии |
| 📊 Распределение | Круговая диаграмма оценок (pie chart) |

**Зависимости:** `common.js`, `rooms/summary.js`, Chart.js

---

### 🔥 Комната 3: SVP Heatmap Pro (`heatmap.html`)
**Назначение:** Тепловая карта выработки по 9 критериям

| Блок | Описание |
|------|----------|
| Таблица тепловой карты | Сотрудники × 9 критериев СВП |
| Алгоритм диагнозов | 7 уровней цветовой индикации |
| Тултипы | Детальная информация при наведении |
| Выезжающая панель | Детализация по клику на сотрудника |
| Легенда | Расшифровка цветов и статусов |

**Зависимости:** `common.js`, `rooms/heatmap.js`, `components.css`

---

### 📈 Комната 4: Аналитика (`analytics.html`)
**Назначение:** История, Сравнение периодов, Тренды + Прогноз

| Вкладка | Описание |
|---------|----------|
| 📜 История | Таблица TQS/AHT/Звонков (detailed/summary) |
| ⚖️ Сравнение | Выбор 2 периодов → дельты по всем метрикам |
| 📈 Тренды + Прогноз | Chart.js график, Holt's Smoothing, R², рекомендации |
| 🏆 Лучшие/Худшие | Колонки под графиком |

**Зависимости:** `common.js`, `rooms/analytics.js` (бывш. `analytics-v2.js`), Chart.js

---

### 👥 Комната 5: Сотрудники (`employees.html`)
**Назначение:** Профили сотрудников, персональные рекомендации

| Блок | Описание |
|------|----------|
| Список сотрудников | Выпадающий список или поиск |
| Персональная карточка | TQS, AHT, активность, тренды |
| История сотрудника | Таблица периодов с цветовой индикацией |
| Рекомендации из PDF | Приоритет 0, тенденции, рекомендации |
| Корреляция TQS/AHT | Влияние времени на качество для сотрудника |

**Зависимости:** `common.js`, `rooms/employees.js`

---

### ⚙️ Комната 6: Настройки (`settings.html`)
**Назначение:** Загрузка файлов, логи парсинга, статус системы

| Блок | Описание |
|------|----------|
| 📤 Загрузка файлов | Drag & drop XLSX/PDF + кнопка загрузки |
| 📋 Логи парсинга | Таблица последних логов (статус, ошибки) |
| 🔧 Статус системы | Health check, версия, статус контейнеров |
| 📥 Экспорт данных | Кнопки: скачать отчёт, выгрузить в Excel/PDF |
| ℹ️ О системе | Версия, документация, GitHub |

**Зависимости:** `common.js`, `rooms/settings.js`

## 🔄 Миграция (как будет происходить)

| Шаг | Действие |
|-----|----------|
| 1 | Создать `src/css/common.css` — вынести общие стили |
| 2 | Создать `src/js/common.js` — API-клиент, утилиты |
| 3 | Создать `src/js/sidebar.js` + `src/js/theme.js` |
| 4 | Разделить `index.html` на 6 комнат |
| 5 | Разделить `analytics-v2.js` на модули |
| 6 | Создать `index.html` как SPA-роутер |
| 7 | Обновить `nginx.conf` |
| 8 | Протестировать все комнаты |
| 9 | Убедиться что ничего не сломалось |

## ❓ Вопросы для корректировки

1. **Количество комнат**: 6 — достаточно? Нужно ли добавить/убрать?
2. **Названия комнат**: устраивают или переименовать?
3. **Главная страница**: должна ли быть отдельной комнатой или фильтры должны быть всегда видны (в сайдбаре)?
4. **Сотрудники**: отдельная комната или встроить в Сводку/Аналитику?
5. **Настройки**: достаточно ли функционала? Может добавить что-то?
6. **SPA vs отдельные HTML**: предпочитаете SPA (один index.html + загрузка контента) или отдельные HTML-файлы для каждой комнаты?
7. **Фильтры (месяц/период/сотрудник)**: должны быть глобальными (в сайдбаре) или локальными (в каждой комнате свои)?
