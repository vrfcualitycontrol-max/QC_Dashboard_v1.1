**Версия:** 1.2

**Статус:** ✅ Утверждён и реализован

## 📋 Описание

Алгоритм диагнозов определяет **статус выработки** каждого критерия СВП на основе **процентного диапазона** выполнения. Каждый диапазон имеет уникальную **цветовую индикацию** и **статус диагноза** для быстрой визуальной оценки качества работы сотрудника.

---

## 🎯 Область применения

- **Инструмент:** SVP Heatmap Pro (тепловая карта командной сводки)
- **Источник данных:** Оценочные листы XLSX (лист «Оценки звонков Soft Collection»)
- **Периодичность:** Неделя / Месяц (выбирается в фильтре дашборда)
- **Единица расчёта:** Процент выработки критерия (среднее по всем звонкам за период)

---

## 🔢 Расчёт процента выработки

### Формула

```
Процент выработки = (Сумма оценок по критерию / Количество звонков) × 100%
```

### Система оценок

| Оценка | Значение | Описание |
|--------|----------|----------|
| `1.0` | 100% | Критерий полностью выполнен |
| `0.5` | 50% | Критерий выполнен частично |
| `0.0` | 0% | Критерий не выполнен |

### Пример расчёта

**Сотрудник:** Иванов И.И.  
**Критерий:** «Аргументация»  
**Период:** 01-08 Фев 2026

| Звонок | Оценка |
|--------|--------|
| 1 | 1.0 |
| 2 | 0.5 |
| 3 | 1.0 |
| 4 | 0.0 |
| 5 | 1.0 |

```
Сумма оценок = 1.0 + 0.5 + 1.0 + 0.0 + 1.0 = 3.5
Количество звонков = 5
Процент выработки = (3.5 / 5) × 100% = 70%
```

**Диагноз:** Недоработка критерия (🟡 жёлтый светлый, 65–74%)

## 🎨 Визуальная индикация

### Принципы цветовой схемы

1. **Градиентный фон** — каждая ячейка имеет градиент от светлого к тёмному оттенку
2. **Цветная граница** — усиливает визуальное восприятие статуса
3. **Внутренняя тень** — создаёт эффект «глубины» для критических уровней
4. **Внешнее свечение** — для 100% ячеек (поощрение отличного результата)

### CSS реализация

```css
/* Пример: 0-24% — Несоответствие СВП */
.svp-cell.range-0-24 {
    background: linear-gradient(135deg, rgba(248, 113, 113, 0.35), rgba(220, 38, 38, 0.25));
    border-color: rgba(248, 113, 113, 0.6) !important;
    box-shadow: inset 0 0 15px rgba(248, 113, 113, 0.15);
}

/* Пример: 100% — Полное соответствие */
.svp-cell.range-100 {
    background: linear-gradient(135deg, rgba(34, 197, 94, 0.45), rgba(22, 163, 74, 0.35));
    border-color: rgba(34, 197, 94, 0.8) !important;
    box-shadow: inset 0 0 20px rgba(34, 197, 94, 0.2), 0 0 10px rgba(34, 197, 94, 0.3);
}
```

## 🔍 Структура диагноза (объект)

Каждый диагноз возвращается как объект со следующими полями:

```javascript
{
    status: 'Несоответствие СВП',          // Полный текст статуса
    shortStatus: 'Несоотв. СВП',           // Сокращённый текст для ячейки
    severity: 'critical-red',              // Уровень критичности (для логики)
    icon: '🔴',                            // Иконка для визуализации
    color: '#f87171',                      // HEX цвет для текста/тултипов
    cssClass: 'range-0-24'                 // CSS класс для стилизации ячейки
}
```

## 💻 Реализация

### JavaScript функция

**Файл:** `index.html`  
**Функция:** `getSvpDiagnosisByPercentage(percentage)`

```javascript
function getSvpDiagnosisByPercentage(percentage) {
    if (percentage >= 0 && percentage <= 24) {
        return {
            status: 'Несоответствие СВП',
            shortStatus: 'Несоотв. СВП',
            severity: 'critical-red',
            icon: '🔴',
            color: '#f87171',
            cssClass: 'range-0-24'
        };
    }
    
    if (percentage >= 25 && percentage <= 49) {
        return {
            status: 'Критическая просадка критерия',
            shortStatus: 'Крит. просадка',
            severity: 'critical-orange',
            icon: '🟠',
            color: '#fb923c',
            cssClass: 'range-25-49'
        };
    }
    
    // ... остальные диапазоны
}
```

### Обратная совместимость

Функция `getSvpDiagnosis(rawScores, isMonthly)` оставлена как обёртка:

```javascript
function getSvpDiagnosis(rawScores, isMonthly = false) {
    const percentage = calculateSvpPercentage(rawScores);
    return getSvpDiagnosisByPercentage(percentage);
}
```

## 📈 Интерпретация результатов

### Уровни критичности

| Уровень | Severity | Действие |
|---------|----------|----------|
| 🔴 Критический | `critical-red` | Немедленное вмешательство, разбор каждого звонка |
| 🟠 Срочный | `critical-orange` | Срочное исправление, персональная работа с сотрудником |
| 🟡 Системный | `warning-yellow-1/2` | Анализ системных ошибок, групповое обучение |
| 🔵 Мониторинг | `info-blue` | Наблюдение в динамике, сравнение с предыдущими периодами |
| 🟢 Норма | `success-green-1/2` | Поддержание уровня, поощрение при стабильности |

### Рекомендации по использованию

1. **Еженедельно:** Проверять тепловую карту, выявлять критические ячейки
2. **При обнаружении 🔴/🟠:** Немедленно разобрать звонки с сотрудником
3. **При обнаружении 🟡:** Провести групповой разбор системных ошибок
4. **При 🔵:** Отследить тренд за несколько периодов
5. **При 🟢:** Поощрить сотрудника, зафиксировать лучшие практики
