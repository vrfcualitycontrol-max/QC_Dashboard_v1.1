## 🔖 Текущая версия: v1.3.0

**Что сделано в v1.3.0 (2026-04-29):**

### 🎨 UI / Тема
- **Светлая тема как основная** — при первом запуске (или без сохранённых настроек) дашборд открывается в светлой теме `#fdfaf6`
- **Тема сохраняется при навигации** — через URL-параметр `?theme=light|dark` + `localStorage`. Нет мигания, нет сброса при переходах.
- **Полностью переведены на CSS-классы** (вместо inline-стилей):
  - Раздел «Инструментарий» — поисковик, секции, кнопки-таблетки
  - Раздел «Мануал» — аналогично
  - Раздел «Нормативная база (Law)» — аналогично
  - Раздел «Механика оценки» — цветные блоки, шрифты, кнопка TQS
  - Раздел «Нормативная база: Механика Оценки» — аналогично

### 🗂️ Сайдбар
- **Состояние сохраняется при навигации** — через URL-параметр `?sidebar=collapsed|expanded` + `localStorage`
- **Компактный режим не раскрывается** при кликах по иконкам — перехватчик в `initSidebar()` проставляет состояние в ссылку
- **Нет мигания/дёрганья** — `initTheme()` замораживает CSS-transition перед применением класса, восстанавливает через `requestAnimationFrame × 2`
- **Кнопка гамбургер** — единственный способ переключения режима сайдбара
- **Исправлен критический баг** в `sidebar.js`: `#main` использовал `toggle('expanded')` вместо `toggle('collapsed')`
- `toggleSidebar()` — определена **только** в `sidebar.js`, в `app.js` только `window.toggleSidebar = toggleSidebar`

### 🔧 Технические улучшения
- Убраны все дублирующие функции: `toggleSidebar` и `toggleTheme` из `sidebar.js` (устаревшие версии)
- Убран глобальный `document.addEventListener('click')` из `app.js` — перенесён в `initSidebar()`
- Удалён "анти-флик" подход через инжекцию `<style>` — заменён на корректное управление `transition`

## 📁 Ключевые файлы и их ответственность

| Файл | За что отвечает |
|---|---|
| `assets/js/app.js` | `initTheme()`, `toggleTheme()`, данные, фильтры, графики |

## ⚠️ Важно для следующего агента

1. **НЕ добавляй inline-стили** для цветов/фонов — только CSS-классы из `tactical-*` системы
2. **НЕ дублируй** `toggleSidebar()` или `toggleTheme()` — они существуют в единственном экземпляре
3. При добавлении нового раздела — добавь ссылку в `sidebar.js` (`initSidebar`), добавь `?theme=` и `?sidebar=` логику (уже работает автоматически через перехватчик)
4. **Версию** обновляй в: `Dockerfile` (строка `# Version:`), `README_AGENT.md`, `PROJECT_STATUS.md`, git tag
