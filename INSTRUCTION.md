## ⚠️ Решение проблем

### Проблема: Git просит логин/пароль при пуше

**Решение 1:** Токен уже вшит в remote URL (текущая ситуация)
```bash
# Проверить текущий URL
git remote -v

# Если нужно обновить:
git remote set-url origin https://vrfcualitycontrol-max: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@github.com/vrfcualitycontrol-max/QC_Dashboard_v1.1.git
```

**Решение 2:** Использовать SSH (альтернативный способ)
```bash
# Сгенерировать SSH ключ
ssh-keygen -t ed25519 -C "your_email@example.com"

# Добавить ключ в GitHub: https://github.com/settings/keys

# Изменить remote на SSH
git remote set-url origin git@github.com:vrfcualitycontrol-max/QC_Dashboard_v1.1.git
```

### Проблема: Конфликт слияния

Если кто-то ещё редактирует репозиторий:

```bash
# 1. Получите последние изменения
git pull

# 2. Разрешите конфликты в файлах (если есть)

# 3. Закоммитьте разрешение конфликтов
git commit -m "Merge conflict resolved"

# 4. Отправьте
git push
```

### Проблема: Случайно закоммитили лишний файл

```bash
# Отменить последний коммит, оставив изменения
git reset --soft HEAD~1

# Удалить файл из индекса
git reset HEAD имя_файла

# Закоммитьте снова без этого файла
git commit -m "Новое сообщение"
```
