# Передача материалов для контента

Этот файл описывает, как передавать материалы для заполнения новых тактических разделов.

## Что уже готово в проекте

- Каркас страниц:
  - `law.html`
  - `instruments.html`
  - `manual.html`
- Рендер-модуль: `assets/js/tactical-pages.js`
- Sidebar в compact-режиме приведен к формату "только иконки"

## Куда складывать ваши материалы (Markdown)

### 1) Нормативная аргументация (Оферта)

Файл:

- `content/law/law-offer.md`

Рекомендуемый формат:

```md
# Нормативная аргументация (Оферта)

## [Пункт оферты]
- Текст условия: ...
- Когда применять: ...
- Когда не применять: ...
- Кейс применения: ...
- Пример реплики оператора: "..."
```

### 2) Инструментарий (light-версия)

Файлы:

- `content/tactical/instruments/manipulation.md`
- `content/tactical/instruments/legending.md`
- `content/tactical/instruments/argumentation.md`
- `content/tactical/instruments/demand-setting.md`
- `content/tactical/instruments/closing-summary.md`

Рекомендуемый формат:

```md
# [Название инструмента]

## Суть
...

## Правильный подход
...

## Дипломатическая составляющая
...

## Примеры в разговорном скрипте
- ...
- ...
```

### 3) Мануал (граф + последовательность)

Файл:

- `content/tactical/manual/manual-flow.md`

Рекомендуемый формат:

```md
# Мануал: граф процесса

## Узлы
- ID: step-1
  - Название: ...
  - Описание: ...
  - Почему это важно: ...

## Связи
- step-1 -> step-2
- step-2 -> step-3

## Основная последовательность
- step-1
- step-2
- step-3
```

## Важно

- Материалы можно передавать частями.
- Пока файл пустой, на странице показывается безопасный шаблон-заглушка.
- После передачи материалов контент подхватится без изменения рабочей аналитики.
