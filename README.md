# QC Dashboard v1.1 - Аналитический дашборд Quality Control

## 📊 Описание проекта

**QC Dashboard** — это профессиональный аналитический дашборд для отдела Quality Control компании Soft Collection. Предназначен для визуализации и анализа показателей качества работы сотрудников колл-центра.

### Ключевые возможности

- **Автоматический парсинг данных** из XLSX и PDF отчетов
- **Тепловая карта СВП** — визуализация выработки по 9 критериям качества
- **Динамика TQS** — отслеживание изменения качества во времени
- **Выработка по критериям** — детальный анализ по каждому критерию
- **Распределение оценок** — круговая диаграмма с общей выработкой по скрипту
- **Персональные рекомендации** — автоматическая генерация на основе PDF отчетов
- **AHT мониторинг** — контроль среднего времени разговора с цветовой индикацией превышений

### Технические особенности

- **Автономная работа** — обновление данных одним запуском парсера
- **Адаптивный дизайн** — тёмная/светлая тема
- **Выдвижное меню** — быстрая навигация по разделам
- **Закреплённые элементы** — кнопка меню и переключатель темы всегда под рукой
- **Профессиональная стилизация** — неоновые цвета, градиенты, эффекты стекла

## 📁 Структура проекта

```
Dashboard_QC/

├── auto_updater.py         # Парсер для извлечения данных
├── requirements.txt        # Python зависимости
├── README.md              # Документация
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск парсера

```bash
python auto_updater.py
```

### 3. Открытие дашборда

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8080
```

Перейдите по адресу: http://localhost:8080

## 📈 Источники данных

### XLSX файлы
- **Лист**: "Оценки звонков Soft Collection"
- **Колонки**: ФИО Сотрудника, Длительность, 9 критериев СВП, Итоги (TQS)
- **Формат имени**: `Quality дд.мм.гггг - дд.мм.гггг.xlsx`

### PDF файлы
- **Секции**: "Отчет по сотруднику: [ФИО]"
- **Данные**: Приоритет 0, Тенденции, Рекомендации

## 🎯 Метрики

### Критерии СВП (9 блоков)
| Критерий | Вес |
|----------|-----|
| Приветствие и прощание, Организация, Идентификация | 5% |
| Этика общения | 5% |
| Выбор корректного результата в CRM | 10% |
| Легендирование | 15% |
| Предоставление информации о задолженности | 10% |
| Аргументация | 20% |
| Манипуляция | 10% |
| Выставление требований — Уточнение способа оплаты | 15% |
| Подведение итогов | 10% |

### Расчёт показателей
- **TQS (Total Quality Score)**: Средний балл по итогам звонка
- **AHT (Average Handle Time)**: Среднее время разговора (мин)
- **Общая выработка**: Взвешенный процент по всем критериям

## 🔧 Настройка

### Добавление новых данных
1. Поместите XLSX и PDF файлы в папку `reports/`
2. Запустите парсер: `python auto_updater.py`
3. Обновите страницу дашборда в браузере

### Изменение периода
Используйте фильтры в верхней части дашборда:
- **Месяц**: выбор месяца отчётности
- **Период**: выбор недельного периода или сводка за месяц
- **Сотрудник**: выбор конкретного сотрудника или все

## 📊 Интерпретация показателей

### Тепловая карта
- 🟢 **Зелёный (≥75%)**: Полное соответствие критерию
- 🟡 **Жёлтый (25-74%)**: Частичное выполнение
- 🔴 **Красный (<25%)**: Несоответствие СВП

### AHT (время разговора)
- **Норма**: ≤3.5 мин
- **Превышение**: >3.5 мин (оранжевый)
- **Критично**: >4.5 мин (красный)

## 🛠️ Расширение функционала
