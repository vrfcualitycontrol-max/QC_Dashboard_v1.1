# QC Dashboard v1.2 — Аналитический дашборд Quality Control

## 📊 Описание проекта

**QC Dashboard** — профессиональный аналитический дашборд для отдела Quality Control компании Soft Collection (Variant Retail Finance). Визуализация и анализ показателей качества работы сотрудников колл-центра.

---

## 🆕 Что нового в v1.2

| Фича | Описание |
|------|----------|
| 🐳 Docker | Полная контейнеризация: nginx + fastapi + postgres |
| 📊 REST API | 13 эндпоинтов для аналитики и интеграций |
| 📜 История | Хранение и просмотр истории показателей |
| ⚖️ Сравнение | Сравнение периодов с дельтами по всем метрикам |
| 📈 Тренды + Прогноз | Holt's Smoothing, R², бизнес-рекомендации |
| 🏆 Leaderboard | Рейтинг сотрудников с трендами up/down/stable |
| 🔗 Корреляция | Анализ связи TQS и AHT (Пирсон) |
| 🎨 SVP Heatmap Pro | 7 уровней диагнозов с цветовой индикацией |
| 📋 Логирование | Отслеживание ошибок парсинга |

## 🚀 Быстрый старт

### 1. Запуск (Docker)

```bash
cd c:\Users\user\AppData\Local\Programs\Microsoft VS Code\Dashboard_QC
docker-compose up -d
```

### 2. Открыть дашборд

**http://localhost**

### 3. Документация API

**http://localhost/docs** (Swagger UI)

### 4. Остановка

```bash
docker-compose down
```

## 📡 API Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/api/health` | Проверка здоровья |
| `GET` | `/api/employees` | Статистика сотрудников |
| `GET` | `/api/leaderboard` | Рейтинг сотрудников |
| `GET` | `/api/leaderboard/best-worst` | Топ-5 лучших/худших |
| `GET` | `/api/correlation/{name}` | Корреляция TQS/AHT |
| `GET` | `/api/history/{name}` | История сотрудника |
| `GET` | `/api/compare/{name}` | Сравнение периодов |
| `GET` | `/api/trends` | Тренды по периодам |
| `GET` | `/api/trends/forecast` | Прогноз (Holt, R²) |
| `GET` | `/api/logs` | Логи парсинга |
| `POST` | `/api/upload/xlsx` | Загрузка XLSX |
| `POST` | `/api/upload/pdf` | Загрузка PDF |

## 🔧 Управление

```bash
# Просмотр логов
docker-compose logs -f backend

# Перезапуск backend
docker-compose restart backend

# Пересборка образов
docker-compose up -d --build

# Полный сброс (удаление данных!)
docker-compose down -v
```
