## 🔄 СИСТЕМА ФИКСАЦИИ ОБНОВЛЕНИЙ

### Команда "зафиксируй"
При получении команды "зафиксируй":
1. Создать backup всех изменяемых файлов в `backups/snapshot_YYYYMMDD_HHMMSS/`
2. Обновить `PROJECT_STATUS.md` (текущий статус)
3. Обновить `VERSION_HISTORY.md` (история изменений)
4. Обновить `AGENT_BRIEF.md` (информация для агента)
5. Создать Git commit с описанием изменений
6. Создать Git tag если это значимая версия

### Кластеризация
- **bugfix** — исправление ошибок
- **feature** — новые функции
- **style** — визуальные изменения
- **docs** — документация
- **data** — обновление данных

### Push в GitHub
```bash
git add .
git commit -m "{type}: {description}"
git tag -a v{MAJOR}.{MINOR}.{PATCH} -m "Version {MAJOR}.{MINOR}.{PATCH}"
git push origin main --tags
```
